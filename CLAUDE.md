## Architecture

**Gromada** is a community platform for the Pochayiv community (Почаївська громада) — a Spring Boot 3.4.5 / Java 17 web app with REST APIs, WebSocket chat, and server-rendered Thymeleaf views.

**Layers** (`com.example.demo`):
- `entities/` — JPA entities (User, Business, Product, Order, Chat, Review, Job, etc.)
- `repository/` — Spring Data JPA repositories (`JpaRepository<Entity, ID>`)
- `service/` — Interface + `*ServiceImpl` pairs; `@Transactional`, `@Transactional(readOnly = true)` for reads
- `dto/request/` and `dto/response/` — manually mapped in service `toResponse()` methods (no MapStruct)
- `controllers/api/` — REST controllers returning `ResponseEntity<T>`
- `controllers/` — Thymeleaf page controllers and WebSocket `ChatController`
- `ai/` — `AiPlatformServiceImpl` implementing `AiPlatformReadInterface` + `AiPlatformWriteInterface` — facade for LLM access
- `configuration/` — `SecurityConfig`, `WebSocketConfig`, `CorsConfig`, `AiApiKeyFilter`

**Database:** PostgreSQL (`jdbc:postgresql://localhost:5432/gromada`). Schema auto-generated by Hibernate (`ddl-auto=update`). Seed data loaded from `src/main/resources/data.sql` on startup (idempotent via `ON CONFLICT DO NOTHING`). Data persists across restarts. Tests use H2 in-memory (see `application-test.properties`).

**PostgreSQL setup:**
```bash
# Create database (one-time)
sudo -u postgres psql -c "CREATE DATABASE gromada;"
# Or with custom user:
# sudo -u postgres psql -c "CREATE USER gromada WITH PASSWORD 'postgres'; CREATE DATABASE gromada OWNER gromada;"
```

**User roles:** `CITIZEN`, `BUSINESS_OWNER`, `ADMIN`, `AI_AGENT`. Spring Security uses form login (default success URL `/businesses/list`) with CSRF disabled.

**AI agent access:** Custom `AiApiKeyFilter` checks `X-AI-API-Key` header (configured via `gromada.ai.api-key` property, defaults to `changeme-dev-key`). Grants `ROLE_AI_AGENT` for `/api/ai/**` endpoints.

**WebSocket:** STOMP over `/ws` (SockJS) and `/ws-native` (raw, for React Native). Simple broker with `/queue` and `/topic` destinations, user-specific prefix `/user`.

## Key Conventions

- Services use `@RequiredArgsConstructor` (Lombok) for constructor injection of final repository fields.
- Entities use `@Enumerated(EnumType.STRING)` for status/role fields; timestamps set manually with `LocalDateTime.now()`.
- All seed passwords BCrypt-encoded; test credentials: `admin/admin123`, `alice/password123`, `cafe_owner/password123`.
- CORS allows all localhost ports (dev only).
- `spring.jpa.open-in-view=false` — be mindful of lazy-loading boundaries; load associations within `@Transactional` service methods.
